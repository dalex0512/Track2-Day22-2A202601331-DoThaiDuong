[02] [prompt-v2] Q: What is overfitting in machine learning?
     A: Overfitting in machine learning occurs when a model learns the training data too well, including its noise, which leads to poor generalization on new, unseen data. An overfitted model performs excellently on training samples but fails to accurately predict outcomes for new examples because it has memorized specific details rather than learning general patterns. Signs of overfitting include a significant gap between training accuracy and validation accuracy. Techniques to combat overfitting include regularization, dropout, early stopping, and collecting more training data.

[03] [prompt-v1] Q: Explain the bias-variance tradeoff.
     A: The bias-variance tradeoff is a key concept in machine learning that describes the balance between two types of errors in a model: bias and variance. High bias leads to underfitting, where the model makes strong assumptions and fails to capture the underlying data patterns, while high variance results in overfitting, where the model is too sensitive to fluctuations in the training data. The goal is to find an optimal model that minimizes total prediction error by balancing both bias and variance.

[04] [prompt-v1] Q: How does regularization prevent overfitting?

[05] [prompt-v2] Q: What is cross-validation?
     A: Cross-validation is a model evaluation technique that provides a more reliable estimate of a model's performance. It involves splitting the dataset into multiple folds, allowing the model to be trained on a portion of the data and tested on another. In k-fold cross-validation, the data is divided into k equal parts, with the model being trained on k-1 folds and tested on the remaining fold, repeating this process k times. Other methods include stratified cross-validation, which maintains class distribution, and leave-one-out cross-validation, where a single sample is used as the validation set.

[06] [prompt-v2] Q: What is backpropagation?
     A: Backpropagation is the core algorithm used for training neural networks. It computes the gradients of the loss function with respect to each weight by applying the chain rule of calculus. The process starts from the output layer and propagates error signals backward through the network, calculating partial derivatives layer by layer. These gradients indicate the contribution of each weight to the total error, and the weights are subsequently updated using methods like gradient descent or its variants, such as Adam, RMSprop, and SGD with momentum, to minimize the loss function.

[23] [prompt-v2] Q: What is dense retrieval?
     A: Dense retrieval is a neural approach to document retrieval that surpasses traditional keyword matching by using neural embeddings to encode both queries and documents. [29] [prompt-v2] Q: What is HNSW?
     A: HNSW (Hierarchical Navigable Small World) is a graph-based algorithm designed for approximate nearest-neighbor search. It constructs a hierarchical graph with multiple layers, where higher layers have fewer nodes and longer-range connections, while lower layers contain all nodes with shorter-range connections. The algorithm allows for logarithmic-complexity searches by starting at the top layer and navigating down to finer layers for increased precision. HNSW is known for its effective balance between search accuracy and speed, making it a popular choice as the default index type in many vector databases.

[30] [prompt-v2] Q: What is hybrid search in vector databases?

The two approaches are merged using Reciprocal Rank Fusion (RRF), which sums the reciprocal ranks from both methods to create a more robust combined ranking. This allows for improved search results by leveraging the advantages of both semantic understanding and exact keyword matching.
